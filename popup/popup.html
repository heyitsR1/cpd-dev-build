How backups work

Everything happens on this computer — nothing is uploaded to any cloud. Backups are saved as ZIP files in Downloads › Claude Backups. Automatic backups run while your computer is on, Chrome is open, and you're signed in to claude.ai; if one is missed, it runs the next time those are true.

How to Use

  1. Go to claude.ai in your browser
  2. Click Projects in the sidebar
  3. Open a project you want to export
  4. Click the extension icon in your toolbar to open this side panel
  5. Click ↺ Refresh to load files and chats
  6. Download files or chats individually, in bulk, or grab the entire project as one ZIP
▶ Watch Tutorial Video

Troubleshoot

Files not showing up? Quick things to try:

  • Click ↺ Refresh Files and wait a moment
  • Refresh the page, then try again
  • Check URL is claude.ai/project/[id] — not chat
  • Hard refresh: CMD/Ctrl Shift R
  • Log out of Claude, log back in, reopen project
  • Try Chrome if you're on a different browser

⚡ Fallback: Ask Claude

Some files (spreadsheets, blobs, etc.) can't be downloaded directly via the API. Copy the prompt below and paste it into your Claude chat to get a downloadable ZIP. 

I need you to create a downloadable ZIP file containing ALL the files in this project's knowledge base. Do NOT regenerate or modify the content — simply copy each file exactly as-is into a ZIP archive and provide a download link. Include every file regardless of format (documents, spreadsheets, images, PDFs, etc.).

Paste this into your Claude chat on the project page.
