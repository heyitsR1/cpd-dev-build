# Claude Project Downloader — v1.20.0 developer build

Early copy of v1.20.0 (Cowork task export) while the Chrome Web Store review finishes.

## Install

1. Click **Code → Download ZIP** on this page, then unzip it.
2. Open `chrome://extensions` and turn on **Developer mode** (top right).
3. Turn off the store version of Claude Project Downloader so the two don't overlap.
4. Click **Load unpacked** and pick the unzipped folder (the one containing `manifest.json`).
5. Refresh your claude.ai tab. If you have a licence key, enter it again in this copy.

When the store update goes live, remove this copy and turn the store version back on. It updates on its own from then on.
